PowerToys FancyZones design reference
======================================

This project references the public Zone-based window-management concepts
implemented by Microsoft PowerToys FancyZones.

PowerToys is available under the MIT License:
https://github.com/microsoft/PowerToys

No PowerToys source files are included in this project. The Zone layout
engine in this project is an independent Python/Win32 implementation.
